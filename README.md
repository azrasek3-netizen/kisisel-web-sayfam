# Kişisel Web Sayfam

Azra Sek'in kişisel web sayfası. Mehmet Akif Ersoy Üniversitesi, hakkımda ve Antalya bölümlerini içerir.

## Dosyalar

- `index.html` — sayfa içeriği
- `style.css` — responsive tasarım
- `maku.jpg` — üniversite logosu
- `kumsalya.jpg` — Antalya fotoğrafı

## Yerelde çalıştırma

`index.html` dosyasını tarayıcıda açmanız yeterli.
